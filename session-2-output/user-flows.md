## Flow 1: New Patient Intake

1. Landing: "Welcome to Community Health" — language selector (EN/ES) → Start
2. Identity: Legal name, DOB, contact info (3 screens, one section each)
3. Insurance: Primary insurance (payer, policy number, plan type)
4. Medical history: Medications, allergies, chronic conditions (condensed vs. paper form)
5. Consent: HIPAA + financial agreement — plain language, must scroll to bottom
6. Confirm & submit: Summary screen with edit links per section
7. Confirmation: Reference number, "your nurse will call your name shortly"

## Flow 2: Returning Patient Update

1. Identity verification: DOB + phone number
2. "Here's what we have on file" — review each section
3. Confirm no changes (one tap) or edit changed sections
4. Submit updated intake
5. Confirmation: "Updated — you're all set"

## Flow 3: Nurse Review View

1. Nurse opens submitted intake by patient name or reference number
2. Sees: summary header (name, DOB, insurance, reason for visit)
3. Can expand each section
4. Flags: incomplete fields, potential data errors
5. One-click "Import to EHR" action
