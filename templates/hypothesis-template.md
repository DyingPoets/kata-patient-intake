# Outcome Hypothesis Template

## Format

We believe that [feature or change]
will result in [measurable outcome]
for [specific persona / user group].

We will know this is true when [metric] reaches [target] within [timeframe].
We will know this is false if [metric] does not reach [threshold] within [timeframe].

---

## Example

We believe that the single-screen language selector at intake entry
will result in a 40% reduction in average intake completion time for non-English-speaking patients
for patients who select a non-English language.

We will know this is true when average intake time for non-English sessions falls below 12 minutes
within 60 days of launch.

We will know this is false if average intake time for non-English sessions remains above 18 minutes
at 60 days.
